# Synora

Synora is an experimental blockchain execution platform written in Rust.

## Architecture

The project will gradually evolve into:

- `synora-core` — blockchain primitives and state
- `synora-types` — transactions and blocks
- `synora-crypto` — cryptographic primitives
- `synora-executor` — transaction execution
- `synora-storage` — persistent blockchain storage
- `synora-network` — peer-to-peer networking
- `synora-consensus` — consensus engine
- `synora-node` — blockchain node

## Status

Early development.
